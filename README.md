# Ego2Real / RoboEgoForge

A human-ego-to-robot data engine. It turns a monocular first-person video of a person using their hands
into robot training data: a robotized observation video, an executable joint trajectory, and a policy-ready dataset.

One contact-consistent 4D hand-object trace drives both the visual branch and the action branch, and a
digital twin verifies every clip by executing it.

Live site: https://lixuan27.github.io/ego2real/
